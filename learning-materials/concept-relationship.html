Agent / Context / Skill 三者之间的关系

简单角色比喻

Skill = 工作说明书：规定好整套任务怎么做

Context上下文 = 短期记忆：保存全程对话内容，保证AI不会遗忘前面的要求

Agent智能代理 = 执行员工：拿着说明书，依靠记忆一步步完成完整任务

逻辑联系

1. Skill提供标准化任务流程；

2. 上下文记录全部对话，防止Agent中途丢失需求；

3. Agent读取Skill规则，结合上下文自动完成整套学习资料的生成。

相互影响

如果上下文长度不足，Agent会丢失前面的指令，就算Skill写得再好也无法完整完成任务。Skill则把一次性的对话方案固化成可以反复使用的项目能力。
